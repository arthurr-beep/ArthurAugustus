The start

IQ-Systems is where my engineering career began in earnest. The work spanned government solutions, enterprise products, and integrations with everything from biometric scanners to RFID readers — the kind of breadth that teaches you very quickly how to ship.

What I built

Lagos State e-CofO

  • Developed the Lagos State e-CofO application — a multitiered system that automates 65% of the processes required to obtain a Certificate of Occupancy in Lagos State.
  • Coded in line with company standards, reducing Time To Market by 20% across the engagement and becoming the project expert for product managers.

Ogun State Employee Information System (OGEIS)

  • Built the Ogun State Employee Information System used for payroll management across the state.
  • Integrated with hardware components including biometric capturing and verification systems, RFID readers, printers, and Topaz devices for signature capture.

School Angel and KYS

  • Led the upgrade of the existing School Angel solution, transitioning from WCF Services to REST APIs, XML to JSON responses, and Win-Form to WPF interfaces.
  • Used Onion Architecture extensively, coding against interfaces with dependency injection and multi-threading to separate API data processing from the desktop UI thread.
  • Launched the KYS (Know Your Staff) solution with integrated visitor management, bridging the gap between casual/home-workers' employers and the employees.
  • Led the backend engineering squad including hiring, mentoring new joiners, and stakeholder management.
