The platform

Bellhop operates booking and logistics services at scale, with b2b customers depending on real-time integration with the core booking system. The platform team owned the APIs that sat between everything.

What I built

High-performance APIs in Go and Python

  • Designed and implemented high-performance APIs in Go and Python using frameworks including Echo, Gin, FastAPI, and Django, supporting large-scale business-critical booking operations.
  • Architected APIs in Go using multithreading, design patterns, goroutines, and channels.
  • Built robust Go APIs for handling large data volumes in PostgreSQL and DynamoDB, prioritizing performance optimization.

Event-driven and middleware patterns

  • Pioneered event-driven implementations through Amazon SQS/SNS for the customer-pro booking flow, handling real-time processing of large datasets with minimal latency.
  • Designed GraphQL APIs serving as critical middleware between b2b customers and the core booking system, improving system reliability.
  • Wrote Go Lambda functions for notifications handling.

Container and deployment hygiene

  • Containerized Python and Go APIs using Docker with multi-stage build patterns optimized for Kubernetes.
  • Designed REST APIs in Python3 for internal tooling solutions — Fast-API and Django applications that achieved a 25% improvement in back-office efficiency compared to the legacy CRM.
  • Documented and integrated third-party RESTful services using Postman and Swagger-UI.
